1. Project Title:
"Creator AI Assistant (ContentAI)"

2. Introduction:

ContentAI is a full-stack AI-powered social media content assistant web application built with Python, FastAPI, and PostgreSQL. The system enables users to upload various media types — images, videos, audio files, documents, and plain text — and automatically generates optimized social media content including captions, hashtags, keywords, emojis, hooks, CTAs, SEO tags, summaries, viral scoring, and translations in 20+ languages. The application integrates multiple AI models including Gemma 3 (via Ollama), YOLOv8 object detection, CLIP image classification, BLIP-2 image captioning, Whisper speech-to-text, and EasyOCR text extraction. It also supports direct social media publishing via Instagram Graph API with OAuth authentication, post scheduling with background workers, content drafts management, analytics dashboards, and multi-format content export (TXT, CSV, DOCX, PDF, JSON). The UI is built with Bootstrap 5 responsive design for a clean, mobile-friendly experience.

3. Purpose:

- Provide a centralized AI-powered platform for content creators to generate, optimize, manage, and publish social media content from a single dashboard.
- Reduce manual content creation effort by automating caption generation, hashtag research, SEO optimization, and multi-language translation.
- Enable direct social media integration for seamless publishing to Instagram, Facebook, LinkedIn, Twitter, Threads, and YouTube.
- Offer analytics and engagement tracking to help creators measure content performance and improve their social media strategy.
- Support multiple media types (image, video, audio, document, text) so creators can work with any content format they have.

4. Objectives:

- Implement a secure user authentication system with JWT tokens, bcrypt password hashing, refresh tokens, and role-based admin access.
- Build a multi-media upload pipeline supporting images (JPG, PNG, WEBP, GIF, BMP, HEIC), videos (MP4, MOV, AVI, WEBM, MKV up to 2 min), audio (MP3, WAV, OGG, M4A, AAC), documents (PDF, DOCX, TXT), and plain text.
- Integrate AI models for intelligent content analysis: YOLOv8 for object detection, CLIP for image classification, BLIP-2 for image captioning, Whisper for audio transcription, EasyOCR for text extraction from images.
- Generate 9 caption styles (default, long, short, funny, professional, travel, business, food, luxury) along with hashtags, keywords, emojis, hooks, CTAs, SEO tags, summaries, and viral scoring.
- Enable content translation to 20+ languages using Ollama LLM with MyMemory API fallback.
- Support content rewriting with 8 tones and 4 length options.
- Provide Instagram Graph API integration with OAuth 2.0 for direct publishing, scheduling, and engagement metrics tracking.
- Build a modular social media provider framework supporting Instagram, Facebook, LinkedIn, Twitter/X, Threads, and YouTube.
- Implement post scheduling with background scheduler and optional n8n workflow automation.
- Provide content drafts management with full CRUD operations.
- Offer analytics dashboard with engagement metrics, content breakdown, and viral score tracking.
- Support multi-format content export (TXT, CSV, DOCX, PDF, JSON) for offline sharing.
- Implement rate limiting (60 requests/min per IP) and in-memory caching for security and performance.
- Build an admin panel with user management, banning/unbanning, statistics dashboard, and system monitoring.

APPENDIX - API Endpoints:

Auth:
- POST /api/auth/register - User registration
- POST /api/auth/login - User login (returns JWT tokens)
- POST /api/auth/refresh - Refresh access token
- GET /api/auth/me - Get current user info

Posts:
- POST /api/posts/upload - Upload media and generate content
- POST /api/posts/{id}/regenerate - Regenerate a specific field
- POST /api/posts/{id}/update - Update generated content
- POST /api/posts/{id}/translate - Translate content to target language
- POST /api/posts/rewrite - Rewrite text with tone and length
- GET /api/posts/history - Get post history with pagination
- GET /api/posts/{id}/export/{fmt} - Export post (txt/csv/docx/pdf/json)
- GET /api/posts/export-all/csv - Export all posts as CSV
- GET /api/posts/{id}/quality - Get quality report for media

Social:
- GET /api/social/platforms - List supported platforms
- GET /api/social/connect/{platform} - Start OAuth connection
- GET /api/social/{platform}/callback - OAuth callback handler
- GET /api/social/accounts - List connected accounts
- DELETE /api/social/accounts/{id} - Disconnect account
- POST /api/social/accounts/{id}/refresh-token - Refresh OAuth token
- GET /api/social/accounts/{id}/status - Get account status
- POST /api/social/drafts - Create draft
- GET /api/social/drafts - List drafts
- GET /api/social/drafts/{id} - Get draft details
- PUT /api/social/drafts/{id} - Update draft
- DELETE /api/social/drafts/{id} - Delete draft
- POST /api/social/schedule - Schedule a post
- GET /api/social/schedule - List scheduled posts
- DELETE /api/social/schedule/{id} - Cancel scheduled post
- POST /api/social/schedule/{id}/publish-now - Publish immediately
- POST /api/social/post-now - Publish content now
- GET /api/social/history - List posting history
- GET /api/social/history/{id}/metrics - Fetch engagement metrics
- GET /api/social/notifications - List notifications
- POST /api/social/notifications/read-all - Mark all as read
- GET /api/social/preview/{post_id} - Get post preview data
- POST /api/social/preview/drafts - Save preview as draft
- PUT /api/social/preview/drafts/{id} - Update preview draft

Admin:
- GET /api/admin/users - List all users
